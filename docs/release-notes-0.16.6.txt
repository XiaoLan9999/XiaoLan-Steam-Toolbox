小蓝Steam工具箱 v0.16.6

本次正式版提供 Windows x64 安装版与便携版，包含此前 0.16.2–0.16.5 本地构建中的已接受功能，以及本次动画背景工作区优化。

动画背景与艺术作品
- Steam.Design 保持内嵌于工具箱，默认展开为全窗口工作区，可退出大屏返回本地工具布局，不再要求外部浏览器。
- 增加适应窗口、手动缩放和 100% 还原；缩放范围 50%–150%，只改变在线页面显示，不改变原作品文件尺寸。
- 菜单独立滚动，底部介绍不再固定压住控件；短窗口中可滚动到输入框及其他操作区域，窗口缩放后重新核对视图边界。
- 默认暂停视频与装饰动画，主背景动态预览由用户按需开启；隐藏或关闭页面时停止预览，不修改原动画文件。
- 裁剪、GIF/WebM 等动画转换仍可能消耗较高 CPU。本次优化针对视口和空闲预览开销，现有证据尚不能把整机卡顿唯一归因于这个模块，不宣称解决全部系统卡顿。
- 在线页面仍需网络，第三方页面变化可能影响适配。作品版权声明、可见性及真正上传由用户确认，不自动提交作品。

截图双模式
- 模式一为默认：通过本机辅助进程与 Steam 截图接口给当前客户端登录账号导入本地截图，不退出 Steam；失败或选错账号时停止，不自动切换模式。
- 模式二为指定账号本地导入：目标不是当前 Steam 账号时，备份并写入本地图库，切到该账号后查看，不退出或重启 Steam。
- 自动退出并重启是独立选项，默认关闭；仅模式二写当前账号且用户再次确认后使用，对非当前账号不触发。
- 两种模式都不是云端上传。模式一要求支持的 Windows x64 Steam 客户端、可运行许可、有效 AppID 和空截图说明；未知客户端版本会停止而非猜测接口地址。
- 已确认及结果不确定的图片不自动重导；按图保存提交记录与核验结果，保留备份和原图校验，避免重复导入。

界面与数据迁移
- 设置可在浅色与暗夜主题间切换，保存选择并恢复；头像、背景和截图图片不反色。
- 清理固定界面说明末尾句号，保留用户昵称、留言、草稿、文件名和原始记录；移除首页底部指定提示。
- 设置新增数据导入，支持本工具 schema 9、最高 256 MiB、DELETE 日志模式的 SQLite 单文件备份。
- 导入会先校验、展示内容数量并明确确认，整体替换而非合并；正常重启工具箱，启动时自动备份旧数据库，再原子应用，不重启 Steam。
- 导入后的账号需要在工具箱重新登录，未完成任务保持暂停，不自动发送或继续重试；登录令牌不从备份导入。
- SQLite 导入不包含 Steam 截图、截图防重记录、艺术作品和其他数据库外文件，迁移时需单独保存。
- 自动旧库备份包含原数据库中的本机加密登录令牌，必须保持私有；它不同于已移除令牌的对外导出文件。

升级、限制与发布安全
- 沿用原本地数据目录，不自动继续已有暂停任务，也不启动模拟、锁定或状态跟随。
- 发布包不含个人账号、Cookie、登录令牌、任务数据库、诊断、备份或签名私钥。
- ASF 接入仍是实验功能，需单独配置与实测，不自动启动机器人。
- 内置更新使用固定公钥验证 Ed25519 发布清单，并核对完整文件大小及 SHA-256。Windows EXE 尚未配置商业 Authenticode 代码签名，可能出现未知发布者提示；更新清单签名不是 Windows 商业代码签名。
