小蓝Steam工具箱 v0.16.14

留言请求兼容
- 仅资料页留言 POST 增加 Steam 网页默认的 X-Requested-With: XMLHttpRequest 标记
- 保持表单字段、正文编码、Cookie、目标、重定向边界及发送策略不变，不自动重复 POST

更精确的留言诊断
- 区分请求连接、已收到响应头、响应体读取、结果校验及 JSON 解析阶段
- 仅记录实际观察到的 HTTP 状态、白名单网络码与有界耗时，不伪造不存在的服务器响应
- 区分 HTTP 错误、响应读取中断及本地超时，避免将外部取消误写为超时，不再只显示笼统 transport-error
- 写入与导出两层白名单，不记录正文、账号、好友、Cookie、令牌、原始错误、堆栈或 URL

发送安全与验证边界
- 待核对项仍保留待核对，不将其当作确定失败或自动重发，避免可能重复留言
- 已有真实 Chromium 离线回归覆盖成功、权限拒绝、HTTP 502 与 HTTP 200 响应截断；未使用真实账号发送留言
- 本版改善兼容性及定位信息，不代表已经证明或排除某个用户的加速器、网络、权限或服务端限制
- 若仍有问题，请提供失败项完整报错及新版脱敏诊断日志；不要为了取日志反复重发待核对项
