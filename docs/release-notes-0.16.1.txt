小蓝Steam工具箱 v0.16.1

本次为正式公开版本，提供 Windows x64 安装版与便携版。
0.16.0 在干净 Windows 环境的测试阶段发现换行与路径兼容性问题，未公开发布安装包；本版修正后正式发布。

主要更新
- 启用统一 Logo：从提供的原画裁切头部、睡帽和少量肩部，保留原有画风。
- 本机已有 AppID 模拟、官方名称与图标、跨游戏子状态模板、同组人数及公开状态字段编辑。
- 按来源 SteamID64 复制状态，提供工具箱与实验性 ASF 双模式。
- 保存的账号自动登录；临时 TLS／网络错误自动退避重连并显示倒计时，不要求反复扫码。
- 留言遇网络／服务请求失败或明确权限拒绝时记录并跳过；已提交但结果不明的保留待核对，不重复发送。
- 按账号独立的“无法留言”分类，保留原有分组与黑名单。
- 运行记录放在发送设置下方，默认折叠、分页读取；完整任务和投递记录持久保存。
- 继续包含好友管理、昵称与解除好友历史、Steam 表情、艺术作品／背景裁剪、内置上传准备、截图导入、中英文与数据导出。

升级与使用
- 安装版可覆盖安装；便携版请保留完整目录，不要只复制主程序。
- 沿用原数据目录，不附带任何个人账号、令牌、任务数据库或诊断文件。
- 升级不自动继续暂停的留言，也不启动模拟、锁定或状态跟随。
- 游戏子状态与人数显示受游戏模板、Steam 版本和查看端布局影响；本机读回不是好友端确认。
- ASF 插件需单独配置，完整在线流程尚待实测；不会自动启动机器人。
- 内置更新使用 Ed25519 签名清单及文件哈希校验。Windows 安装程序尚无商业 Authenticode 签名，可能显示未知发布者提示。

下载资产
Setup：安装版；Portable：便携版；SHA256SUMS.txt：文件哈希；update-manifest.json：内置更新签名清单。
