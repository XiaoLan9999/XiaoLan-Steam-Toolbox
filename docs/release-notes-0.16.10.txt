小蓝Steam工具箱 v0.16.10

本机游戏模拟并行覆盖
- 其他不同 AppID 的游戏或快捷方式运行时，允许直接启动本机 AppID 模拟，尝试覆盖 Steam 游戏展示
- 启动、更新子消息和后台检查使用同一活动策略，不再仅因另一个游戏运行或切换而自动停止
- 不结束真实游戏、不修改其 DLL 或其他游戏文件，不建立个人 CM／聊天登录
- 停止只退出本工具自己的占位进程；Steam 决定展示优先级及切回时机，不保证好友端立即恢复显示

保留的边界
- 同一目标 AppID 已活动时仍拒绝新建模拟；修改该真实游戏的子状态请使用“真实游戏状态”编辑／锁定
- 模拟运行后要启动相同 AppID 的真实游戏，必须先停止模拟；当前 AppID 活动标志不能区分两个进程的字段归属
- 工具箱账号、Steam 和 owner 进程绑定、许可、DLL 校验、原生锁定恢复及截图导入互斥不变
- 更新不自动启动模拟或继续暂停的留言任务

发布验证
- 包含离线并行活动、启动竞态、真实 broker 协议、监控、更新与停止边界回归，不将本机接口接受冒充好友端显示确认
- 0.16.9 候选未公开安装包；本版为共享 Windows CI 增加有界测试时间预算，保留所有断言及显式单项期限
- 不改变软件的留言间隔、网络请求、原生状态或数据库操作超时
