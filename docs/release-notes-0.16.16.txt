小蓝Steam工具箱 v0.16.16

账号连接与临时网络恢复
- 安全登录交换及只读请求增加系统 Chromium、全新系统通道、独立直连 Chromium 和 Node HTTPS 兜底，按主机复用成功线路
- 直连仅在系统对当前地址的代理结果为 DIRECT 时允许；Node 还要求没有环境代理，不静默绕过代理，不修改系统或加速器设置
- 候选 Cookie 的身份核验在同一有时限、可取消的恢复中有限重试，不因一次读取抖动便重新交换全部登录信息
- 临时续期失败保留已有可信会话及保存的凭据；尚未核验的候选不能发送留言
- Community 交换阶段的拒绝不再被单独误判为刷新令牌已撤销
- 所有通道均不可达时继续保留凭据并退避，不假装已连接，也不要求反复扫码

界面异常与白屏诊断
- 顶层渲染、模块启动或界面连接异常时显示可读恢复页，提供手动重新载入和诊断导出
- 不自动重新载入；不会因恢复按钮新建或重发留言任务，未保存输入会丢失，已有后台任务需在任务列表核对
- 记录界面错误类别、窗口前后台、载入、无响应及连接路线阶段，保留固定枚举和有界数字
- 不保存原始错误或堆栈、账号、正文、Cookie、令牌、代理地址或完整 URL

保留的安全边界
- 留言 POST、密码登录及验证码提交不自动切换线路重放，结果不确定的留言仍只读核对
- HTTP 403／429、证书错误及取消不做普通网络换路，保留服务端等待要求与证书验证
- 不自动重启 Steam、结束游戏或修改真实游戏状态，不使用更新镜像传递 Steam 登录信息
- 已验证多路恢复和界面错误兜底的离线行为；用户现场仍需 Steam 社区可达。此次白屏自行恢复，尚不能唯一确定其根因
