小蓝Steam工具箱 v0.16.7

本次正式版包含截图双模式、暗夜主题、数据导入，以及动画背景工作区和空闲负载优化。0.16.6 在干净 Windows 发布测试中被临时目录路径兼容检查拦截，未发布安装包；本版修正测试环境的短路径与真实路径处理，保留原安全边界。

动画背景与艺术作品
- Steam.Design 仍内嵌于工具箱，默认展开全窗口工作区，可退出大屏返回本地工具布局
- 支持适应窗口、50%–150% 手动缩放和 100% 还原，缩放不改变作品原文件尺寸
- 左侧菜单独立滚动，底部介绍不再压住输入框和其他操作区域
- 默认暂停视频与装饰动画，按需开启主背景动态预览；隐藏、最小化或关闭页面后停止预览
- 保留动画元数据加载与原文件，不以封面代替动画；裁剪或转换动画仍可能占用较高 CPU
- 实测确认持续动效带来额外负载、暂停后空闲负载下降，但未复现整机严重卡顿，不宣称唯一归因或解决全部系统卡顿
- 在线页面仍需网络，真正上传、可见性和作品版权确认由用户操作

截图双模式
- 模式一为默认：通过本机辅助进程与 Steam 截图接口给当前客户端账号免重启导入本地截图；失败不自动切换模式或退出 Steam
- 模式二为指定账号本地导入：非当前账号直接准备本地图库，提示切号后查看，不退出 Steam
- 自动退出并重启是独立选项，默认关闭；仅模式二写当前账号并再次确认后使用
- 两种模式都不是云端上传，保留备份、逐图核验与防重导记录；结果不确定的图片不自动重复导入
- 模式一要求受支持的 Windows x64 Steam 客户端、可运行许可、有效 AppID 和空截图说明；未知版本停止而非猜测接口

界面与数据迁移
- 浅色／暗夜主题可切换并保存，头像和图片不反色
- 清理固定界面文案末尾句号，保留用户昵称、留言、草稿和文件名原文；移除首页底部指定提示
- 设置新增数据导入：支持工具箱 schema 9、最高 256 MiB、DELETE 日志模式的 SQLite 单文件备份
- 导入先校验、展示数量并确认，整体替换而非合并；重启工具箱时备份旧库并原子应用，不重启 Steam
- 导入不带登录令牌，账号需重新登录，未完成任务保持暂停，不自动发送或继续重试
- 旧数据库大于导入文件上限仍可流式校验和安全备份；导入文件本身的上限不变
- SQLite 导入不包含 Steam 截图、截图防重记录、艺术作品或其他数据库外文件，需单独迁移
- 自动旧库备份包含原数据库中的本机加密登录令牌，应保持私有；它不同于已移除令牌的导出文件

升级与发布安全
- 沿用原数据目录，升级不自动开启已有暂停任务、游戏模拟、锁定或状态跟随
- 发布包不含个人账号、Cookie、登录令牌、任务数据库、诊断、备份或签名私钥
- ASF 接入仍为实验功能，需单独配置与实测，不自动启动机器人
- 内置更新用固定公钥验证 Ed25519 清单，并核对文件大小和 SHA-256
- Windows EXE 尚无商业 Authenticode 代码签名，可能显示未知发布者；更新清单签名不等于商业代码签名
