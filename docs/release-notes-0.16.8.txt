小蓝Steam工具箱 v0.16.8

诊断日志
- 设置 → 运行诊断增加“导出诊断日志”和“打开日志目录”
- 登录报错处也可直接导出，不需要先登录成功或分享数据库
- 记录匿名本地尝试序号、登录阶段、网络错误类别／白名单代码、HTTP 状态、Steam EResult 与耗时，便于区分二维码获取、轮询和网页会话建立失败
- 自动轮转两份各最多 1 MiB 日志；导出固定两文件的有界快照，最多保留最近 5000 条合法事件
- 导出为单个 JSON，附软件、Electron／Node／Chromium 和系统平台版本；由用户自行选择位置并手动转交，不自动上传
- 写入与导出均采用白名单字段，不包含账号、好友、留言、密码、验证码、登录令牌、Cookie、二维码内容、完整 URL 或异常堆栈
- 导出时再次过滤历史／异常内容，拒绝链接或数据目录内目标，不覆盖已有文件，也不修改原日志
- 数据备份包含个人数据，不能代替诊断日志分享；诊断报告不打包数据库或整个数据目录

登录界面
- 失败后清除已失效二维码，明确提示刷新，不继续显示旧码
- 关闭或切换登录方式时作废迟到响应，并取消迟到的登录会话
- 补齐 Steam SDK WebAPI 403／429 的安全分类
- 不改变登录报文、证书校验和重试配置，不会自动扫码或替用户确认登录

这些改动提供故障证据并修正界面生命周期，不代表已确认所有扫码错误的网络根因

给朋友排查：更新后复现一次错误 → 在登录报错处或设置中导出诊断日志 → 将 JSON 文件转交维护者

继续使用原数据目录；升级不自动恢复暂停任务或启动游戏状态工具
内置更新仍核验 Ed25519 清单和 SHA-256；Windows EXE 尚无商业 Authenticode 签名
