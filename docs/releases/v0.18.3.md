# 小蓝Steam工具箱 v0.18.3

正式发布，包含此前 0.17.0–0.18.3 本地预览版的功能与修正

## 新功能

- Steam 客户端缓存账号卡片与右键操作，支持备注、资料链接、userdata、快捷方式和确认后的正常切号
- 本地 `.maFile` 导入、Steam Guard 验证码、私密备份导出和已有急救码查看
- 手动交易／市场确认列表与逐项原生确认，不提供无人值守自动接受
- 实验性新建令牌向导，包含独立登录、手机号／邮件／短信步骤、候选资料落盘、备份门槛与待完成流程恢复
- 系统托盘驻留，首次关闭时选择退出或隐藏，并可记住设置
- 同风格明暗主题标题栏，简化欢迎页与侧栏

## 优化与修正

- 窗口失去焦点、最小化或隐藏时暂停视觉工作，减少头像加载和重复界面更新；后台任务及保活照常进行
- 本机模拟空闲时不再每 250 ms 重复调用完整 Steam 接口检查，输入采用事件唤醒，不做 25 ms 空转
- 外层模拟监控从每 3 秒完整活动扫描改为每 15 秒轻量身份读取，保留每次实际操作及写入边界的完整校验
- 更新线路测速、下载测速与当前线路详情默认折叠，保留进度和取消按钮；默认按实测下载试读速度选线，失败后换线
- 重试下载重新测速时清除上一轮线路／实时速度显示，保留安全断点续传
- 补充界面文案目录生成及安全回填说明

## 使用与验证边界

- 升级沿用原数据目录，不自动开始发送、模拟、令牌绑定或交易确认
- 令牌秘密使用本机 Windows DPAPI 加密，普通 SQLite 数据导出不包含它们；跨机器请先单独私密导出，不要分享令牌文件或急救码
- 绑定、短信和交易确认已通过离线合成会话测试，尚未进行真实账号安全操作的完整实测；请按原生确认提示逐步核对，不将本版视为已经完成服务器兼容性验证
- 睡觉状态原生写入仍禁用；虚假 VR／Steam Deck 标识没有可用实现
- 后台开销的调用路径已减少，未声称已证明所有 Steam 好友列表卡顿、白屏或外部网络问题的根因及恢复
- 更新线路质量可能变化，小文件试读不保证完整安装包始终可达
- 提供安装版、便携版、Ed25519 签名更新清单与 SHA-256 校验文件；更新清单签名不等同于 Windows EXE 的 Authenticode 签名
